# 🤖 Chat Bot (Web Project)

A multi-page web project built with **HTML, CSS, and JavaScript**.  
Includes calculator, SQL demo, and weather app with interactive features.

## 📂 Project structure
- `index.html` → Homepage
- `calci.html` → Calculator
- `sql.html` → SQL demo page
- `weather.html` → Weather app
- `style.css`, `weat.css` → Stylesheets
- `script.js`, `went.js`, `eat.js` → JavaScript files
- `assets/` → Images and other resources

## 🚀 Features
- Chatbot-style UI
- Calculator functionality
- Weather information page
- SQL info/demo page
- Responsive design with CSS

## ▶ Run locally
1. Download the repo.
2. Open `index.html` in a browser.
